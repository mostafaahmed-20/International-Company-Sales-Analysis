# International Company Sales Analysis

This project analyzes international sales data using Python to uncover trends, top-performing regions, and actionable business insights.

## 📊 Project Objectives
- Clean and explore raw sales data
- Visualize trends by region, product, and time
- Identify key insights to inform business strategy

## 🛠 Tools & Libraries
- Python
- Pandas
- Matplotlib / Seaborn
- Jupyter Notebook
- plotly.express

## 📁 Folder Structure
- `data/` – Raw or cleaned CSV files
- `notebooks/` – Jupyter notebooks for exploration and analysis
- `scripts/` – Python scripts for cleaning or transforming data
- `images/` – Exported charts and visualizations

```bash
pip install -r requirements.txt
jupyter notebook notebooks/sales_analysis.ipynb
